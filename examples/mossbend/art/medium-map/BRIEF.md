# Medium environment image: Birkenfurt

The user requested a materially larger, richer map after the one-tree SAM 3 test,
and questioned Retro Diffusion's resolution suitability. This stage authors the
new environment image for inspection; it is not a completed playable world.

- Technique: one composed landscape image, preserving object/terrain integration.
- Provider for this image: built-in ImageGen. Live Retro Diffusion MCP checks on
  2026-09-11 returned 256 x 256 maxima for RD Pro Isometric/Edit and 384 x 384 for
  RD Plus Default. Changing output resolution is not itself a composition fix.
- Reference: the user's supplied forest illustration, for style/material treatment
  only. Original layout and architecture; no copied characters, branding or HUD.
- Scope: medium woodland district with a three-cottage hamlet, village clearing,
  winding stream, two crossings, raised forest clearing and a connected route loop.
- Ground fills the frame. Paths blend into grass; foundations, roots and banks are
  composed together. Trees stay outside circulation and door approaches.
- Request approximately 1536 x 1024; record actual decoded output dimensions.
  A larger raster does not prove a consistent native pixel grid.
- No baked actors, creatures, UI or particles. Keep the existing SAM test intact.
- Inspect image composition and the key joins before any broader gameplay binding.
  SAM masks remain the intended occlusion technique; this image alone does not
  establish collision, depth, animation or complete-world acceptance.
