# Variant A: animation first

Inspect source frames and choose the intended water/particle motion. Bind one
looping named clip and play it at a useful speed before tiling or assembling the
scene. Keep stationary stonework still and use simulation-driven animation so
pause freezes the environment. Then repeat compatible modules with coherent phase.

Compose the fountain and bridge around those working loops. Keep image size,
ground contact and collision separate; use existing runtime floors and links for
walkable raised surfaces. Inspect the large asset beside the actor, its footprint,
and foreground/background ordering. Check crossing the bridge and passing below.

Use the runtime art guide and existing art-integration skill when measurements
or bindings are unclear. Record source/frame choices, placement decisions, and
what was actually checked. Do not change engine code or claim generated art
quality from this authored calibration asset. Stop after the requested scene.
